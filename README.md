Sistema RAT Digital

Sistema web desenvolvido para preenchimento digital e geração de Relatórios de Atendimento Técnico (RAT) em PDF.

O projeto foi desenvolvido com foco em praticidade, permitindo que o técnico preencha as informações diretamente pelo celular ou computador, registre assinaturas digitais e gere o documento final em PDF.

Funcionalidades:

Preenchimento de dados do cliente
Registro de endereço, chamado e localização
Cadastro de equipamentos
Registro de materiais utilizados
Campo para laudo técnico
Registro de horários de atendimento
Dados do cliente e contato
Assinatura digital do cliente
Assinatura digital do técnico
Preenchimento automático de um modelo PDF
Geração do PDF final
Compartilhamento do PDF pelo dispositivo
Download automático quando o compartilhamento não está disponível
Interface responsiva para celular e computador
🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript
Bootstrap 5
Bootstrap Icons
PDF-LIB
HTML Canvas API
Web Share API

Objetivo:

O sistema foi criado para digitalizar e facilitar o processo de elaboração de Relatórios de Atendimento Técnico, reduzindo a necessidade de preenchimento manual de documentos e tornando o processo mais rápido e organizado.
